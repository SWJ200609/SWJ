## 查词功能

在「单词查询」页里可以：

- 按拼写模糊检索（不区分大小写，输前几个字母即可）
- 按考试、批次、词性、掌握状态筛选，也可切换排序
- 看音标、词性、中文释义和例句，以及这个词出现在哪些批次里
- 标记「已掌握 / 忘了」，进度记在自己的浏览器里
- 按 `/` 快速聚焦到搜索框

页面支持 URL 参数，方便做书签和深链：

```
words.html?q=abandon            # 直接查某个词
words.html?exam=cet6&batch=3    # 只看某张词表的某一批
words.html?pos=n&st=unlearned   # 按词性 / 掌握状态筛
words.html?sort=ipa             # 按某种顺序排
```

首页和两个计划页顶栏的「跳转查词」也会把输入的词带过去。

## 使用与隐私

- **完全离线可用**：词库编译在 `assets/words.js` 里，随页面一起下载，之后浏览器里所有检索都不发请求。没有 CDN、没有外部字体、没有 `fetch()`，国内网络直接能开。
- **进度只存在本地**：「已掌握」的进度存在浏览器的 `localStorage`（key `ky.words.mastery.v1`），主题存在 `ky.site.theme`。清浏览器数据会一起清掉，不会有任何数据发到服务器。
- **深色 / 浅色**：右上角切换，默认跟随系统。
- **手机可用**：顶栏按钮打开侧边导航。

## 说明

- 页面里写的分值占比、时间投入、通过线等都是备考参考值，请以教育部考试中心的官方大纲、最新真题首页和考试大纲为准。
- 词表是按考试大纲整理的常用高频词，不代表完整的官方词汇表。
- 仓库名请勿改名：`404.html` 用的是 `/SWJ/...` 绝对链接，用户浏览器里的进度也按域名保存，改名后链接和已有进度都会受影响。
