🔀 近义词辨析

考研必考 20 组 · 完形/翻译/写作三处都能用

用法：每组记住「最核心的那一个区别」，不要背定义——考场上是「二选一」，不是「背释义」。

affect ↔ effectv. / n.高频辨析影响（动词）/ 效果（名词）

核心区别：affect 动词（影响）｜effect 名词（效果）；有例外 effect 也可作动词 = 使实现

例句：The weather affects my mood. / the effect of the new policy / effect a change（实现变革）

考点：完形填空高频考点，考 a/e 词性区分

principal ↔ principlen./adj. / n.高频辨析主要的／校长 / 原则

核心区别：principal 主要的（adj.）／校长（n.）｜principle 原则（n.）

例句：the principal reason（主要原因）/ work out a principle（想出一条原则）

考点：形近，翻译常考

complement / compliment / supplementn./v.高频辨析补充 / 赞美 / 增补

核心区别：complement 补足（使之完整）｜compliment 赞美（i 像 smile）｜supplement 增补（额外加）

例句：The two skills complement each other. / pay a compliment to sb. / a vitamin supplement

考点：三个 i/u 形近，完形必考

discreet ↔ discreteadj.高频辨析谨慎的 / 分离的

核心区别：discreet 谨慎的、细心的（e 像 careful）｜discrete 分离的、独立的（e 像 separate）

例句：be discreet about personal matters / discrete units

consequence ↔ sequencen.高频辨析后果 / 顺序

核心区别：consequence 后果（con 共同 + sequence 顺序 = 一个事件引发的后续）｜sequence 顺序、序列

例句：in consequence of / a natural sequence

confine ↔ confirmv.高频辨析限制 / 确认

核心区别：confine 限制（把某人限制在某处）｜confirm 确认

例句：confine oneself to / confirm the appointment

考点：confirm ≠ concur（同意），是另一个常混对

comply / concur / conspirev.高频辨析遵守 / 同意 / 密谋

核心区别：comply 遵守（法规）｜concur 同意、同时发生｜conspire 密谋（贬义）

例句：comply with the law / concur in the opinion / conspire to commit a crime

personnel / personal / persuaden./adj./v.高频辨析全体人员 / 个人的 / 说服

核心区别：personnel 全体人员、人事（n.，不可数）｜personal 个人的（adj.）｜persuade 说服（v.）

例句：hospital personnel / a personal opinion / persuade sb. to do

economical ↔ economicadj.高频辨析节约的 / 经济的

核心区别：economical 节约的、实惠的（省时间/钱）｜economic 经济的（学科/领域）

例句：an economical car（省油车）/ an economic crisis（经济危机）

考点：英语二经济类文章必考

historic ↔ historicaladj.高频辨析历史上著名的 / 历史的

核心区别：historic 历史上著名的、有重大意义的（强调「重要」）｜historical 历史的、关于历史的（强调「学科」）

例句：a historic moment（历史性时刻）/ historical research（历史研究）

continual ↔ continuousadj.高频辨析频繁的 / 连续的

核心区别：continual 频繁的、断断续续的（有停顿）｜continuous 连续的、不间断的（毫无中断）

例句：continual interruptions（不断被打扰）/ continuous growth（持续增长）

assure / ensure / insurev.高频辨析使确信 / 确保 / 投保

核心区别：assure 使某人确信（assure sb. of sth.）｜ensure 确保（结果）｜insure 投保（商业）

例句：assure me of your safety / ensure success / insure the house

raise / rise / arousev.高频辨析举起/筹集 / 上升 / 激起

核心区别：raise 及物（举起/筹集）｜rise 不及物（上升）｜arouse 激起（情感）

例句：raise funds / prices rise / arouse interest

lay ↔ liev.高频辨析放/产卵 / 躺/说谎

核心区别：lay 及物（放）lie-lain-lain｜lie 不及物（躺）lay-lain-lain；lie 也有「说谎」lie-lie-lied

考点：不规则动词，翻译完形写作都考

loose ↔ loseadj. / v.高频辨析松的 / 丢失

核心区别：loose 松的、宽松的（adj.）｜lose 丢失、输掉（v.）

考点：发音 /luːs/ 相同，拼写差一个 e，是最高频的拼写陷阱

weather ↔ whethern. / conj.高频辨析天气 / 是否

核心区别：weather 天气（n.）｜whether 是否（conj.）

考点：拼写陷阱，写作中经常写错

further ↔ fartheradv./adj.高频辨析进一步 / 更远

核心区别：further 进一步（比喻/抽象）｜farther 更远（物理距离）

例句：for further information（详细信息）/ run farther（跑更远）

artificial ↔ artisticadj.高频辨析人工的 / 艺术的

核心区别：artificial 人工的（与自然相反）｜artistic 艺术的、有艺术感的

考点：英语二「人工智能」= artificial intelligence，必背

benefit / profit / advantagen.高频辨析好处 / 利润 / 优势

核心区别：benefit 好处、福利（可抽象）｜profit 利润、利益（常商业）｜advantage 优势（相对）

例句：for the benefit of the public / turn a profit / have an advantage over

decision ↔ determinationn.高频辨析决定 / 决心

核心区别：decision 决定（选择）｜determination 决心（意志力）

例句：make a decision / show determination
