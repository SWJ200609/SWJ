🎓 考研英语二 核心词

113 词 · 5 主题 · 英语二题材以经济、社会、应用为主

考研英语二的考点角度与 CET-6 不同：更问「和谁搭配、在翻译里怎么处理、完形里怎么区分」。

① 经济与商业 · 26 词

boost/buːst/v./n.高频经济促进；增加；推动

搭配boost confidence / the economy / sales / demand

辨析boost 快速推动 → enhance 提升质量 → promote 推广

翻译「促进经济增长」= boost economic growth

出题完形高频；大作文「有效措施」常用

marginal/ˈmɑːdʒɪnl/adj.高频经济边缘的；微小的；边际的

搭配a marginal increase / role；marginal cost 边际成本

辨析marginal 微小的（几乎无影响） → slight 轻微的 → negligible 可忽略

出题「微不足道的变化」最佳译法

stimulate/ˈstɪmjuleɪt/v.高频经济刺激；促进

搭配stimulate growth / demand / consumption / competition

辨析stimulate 外部刺激 → encourage 鼓励 → motivate 激励（内在动机）

出题大作文「刺激消费」高频

allocate/ˈæləkeɪt/v.高频经济分配；拨出

搭配allocate resources / funds to…；allocation n.

辨析allocate 计划性分配 → distribute 分发 → assign 指派

出题完形搭配题；介词 to 必考

consume/kənˈsuːm/v.高频经济消费；消耗

搭配consumer n.；consumption n.；consume time / energy

辨析consume 消耗 → spend 花费 → deplete 耗尽

出题「消费者」= consumers；「消费水平」= level of consumption

revenue/ˈrevənjuː/n.高频经济收入；税收

搭配government / tax revenue；increase revenue

辨析revenue 机构总收入 → income 个人收入 → profit 利润 → earnings 净得

出题四词辨析是英语二经济文送分位

substitute/ˈsʌbstɪtjuːt/v./n.高频介词替代；替代品

搭配substitute A for B（用 A 代替 B）→ 与 replace B with A 对照，高频陷阱

辨析substitute 用替代品 → replace 更换 → exchange 交换

出题介词方向是完形与翻译双考点

crucial/ˈkruːʃl/adj.高频写作至关重要的

搭配crucial to…；play a crucial role in

辨析crucial 决定性关键 → vital 生死攸关 → important 一般重要

出题大小作文必用；介词 to 必考

efficient/ɪˈfɪʃənt/adj.高频辨析高效的

搭配be efficient in / at；efficiency n.

辨析efficient 效率高（省时省料） ↔ effective 有效果（达到目的）

出题「经济又高效」= economical and efficient；形近 classic 陷阱

derive/dɪˈraɪv/v.高频介词获得；源于

搭配derive A from B；derive from（源自）

辨析derive 源于 → originate 起源于 → stem 源自（stem from）

出题翻译「从……中获益」= benefit/derive benefit from

emerge/ɪˈmɜːdʒ/v.高频介词出现；涌现；显露

搭配emerge from…；emerging markets；emerged adj.

辨析emerge 逐渐显现 → appear 突然出现 → arise 产生（问题/需求）

出题翻译「新兴经济体」= emerging economies

facilitate/fəˈsɪlɪteɪt/v.高频写作促进；使便利

搭配facilitate trade / communication / growth

辨析facilitate 使过程更顺 → promote 推广 → enable 使能够

出题大作文「简化流程」最佳用词

generate/ˈdʒenəreɪt/v.高频经济产生；发电；引起

搭配generate income / revenue / interest / controversy

辨析generate 产生（可计量） → produce 生产 → cause 引起（常负面）

incentive/ɪnˈsentɪv/n.高频经济激励；动机

搭配provide / offer an incentive for…；financial / tax incentives

辨析incentive 激励（可具体化） → motivation 内在动机 → stimulus 刺激

出题介词 for；政策类文高频

launch/lɔːntʃ/v.高频商业发起；发射；上市

搭配launch a campaign / product / investigation / satellite

辨析launch 正式发起 → initiate 启动（流程） → start 开始

出题「推广活动」= advertising campaign

migrate/ˈmaɪɡreɪt/v.高频社会迁移；移居

搭配migrate from A to B；migration n.；migrant workers 农民工

辨析migrate 迁移（常季节性/群体） → emigrate 移居国外 → immigrate 移居入境

出题城乡人口流动是英语二高频题材

minimize/ˈmɪnɪmaɪz/v.高频写作最小化；减少

搭配minimize losses / risk / cost；minimally adv.

辨析minimize 减少到最低 → reduce 减少 → decrease 下降

出题大作文建议段常用「降低……的影响」

negotiate/nɪˈɡəʊʃieɪt/v.高频商业谈判；协商

搭配negotiate with sb. about/on sth.；negotiations n.

辨析negotiate 双向协商 → discuss 讨论 → bargain 讨价还价

perceive/pəˈsiːv/v.高频心理感知；认为

搭配be perceived as…；perceive A as B；perception n.

辨析perceive 主观感知 → recognize 辨认 → realize 意识到

出题「被普遍视为」= be widely perceived as

pursue/pəˈsjuː/v.高频人物追求；追赶

搭配pursue one's dream / goal / career；pursue a degree

辨析pursue 主动追求 → chase 追赶 → follow 跟随

出题「攻读学位」= pursue a master's degree

resolve/rɪˈzɒlv/v./n.高频写作v. 解决；n. 决心

搭配resolve a conflict / dispute；with the resolve to do

辨析resolve 解决（难题） → solve 解答（问题） → settle 处理（事务/争端）

出题一词多义（v./n.）；翻译高频

secure/sɪˈkjʊə(r)/v./adj.高频写作v. 保障；adj. 安全的

搭配secure a loan / job / future；make sth. secure

辨析secure 确保获得 → guarantee 保证 → ensure 确保（结果）

出题写作「确保未来」最佳替换

sustain/səˈsteɪn/v.高频环境维持；支撑；承受

搭配sustain growth / damage / losses；sustainable adj. 可持续的

辨析sustain 长期维持 → maintain 保持（人为） → support 支撑

出题「可持续发展」= sustainable development

transition/trænˈzɪʃn/n./v.高频社会转变；过渡

搭配in transition；a transition from A to B；transition period

辨析transition 过渡（过程） → transformation 变革（结果） → change 变化

出题「转型期」= transition period

unemployment/ʌnɪmˈplɔɪmənt/n.高频社会失业

搭配unemployment rate；high / low unemployment；the unemployed 失业者（群体）

辨析unemployment 失业（状态） → joblessness 无业 → layoff 裁员（动作）

出题the + adj. 表群体，必考点

validate/ˈvælɪdeɪt/v.次高频科研使有效；验证

搭配validate a result / account / hypothesis

辨析validate 验证有效 → verify 核实 → confirm 确认

出题「数据验证」= validate data

② 科技与网络 · 24 词

algorithm/ˈælɡərɪðəm/n.高频科技算法

搭配search / recommendation algorithm

辨析algorithm 算法（程序逻辑） → program 程序 → data 数据

翻译「算法推荐」= algorithm-based recommendation

artificial intelligence/ˌɑːtɪˈfɪʃl ɪnˈtelɪdʒəns/n.高频科技人工智能

搭配artificial intelligence (AI)；AI-driven 人工智能驱动的

辨析artificial 人工的 ↔ natural 自然的

出题大小作文热点词；不可数，不加复数

app/æp/n.高频科技手机应用程序

搭配a mobile app；app download / update；application n. 申请、应用

辨析app 手机应用 → application 广义应用/申请 → programme 项目

出题「应用程序」= app / mobile application；application 一词多义

bandwidth/ˈbændwɪð/n.次高频科技带宽

搭配narrow / wide bandwidth；broadband 宽带

辨析bandwidth 网络带宽 → capacity 容量 → traffic 流量

出题比喻义「精力、时间」也常考

capacity/kəˈpæsəti/n.高频经济容量；能力

搭配storage / production capacity；in one's capacity as 作为……身份

辨析capacity 容量与能力（一体两义） → ability 能力 → volume 体积

出题「生产能力」= production capacity；一词两义是翻译与完形常考点

cloud/klaʊd/n.高频科技云（技术）；云存储

搭配cloud storage / computing；the cloud

辨析cloud 云端（比喻） ↔ cloud 云层（本义）

翻译「云计算」= cloud computing

data/ˈdeɪtə/n.高频科技数据

搭配large-scale data；data security / analysis / mining

辨析data 是 datum 的复数；现代英语可作不可数名词，谓语常用复数

出题「大数据」= big data；「数据安全」= data security

device/dɪˈvaɪs/n.高频科技设备；装置

搭配mobile / audio / input device；consumer device

辨析device 具体设备 → equipment 成套装备（不可数） → instrument 仪器 → tool 工具

出题「智能设备」= smart devices

digital/ˈdɪdʒɪtl/adj.高频科技数字的

搭配digital economy / technology / payment；digitize v. 使数字化

辨析digital 数字的/数码的（同形两义）

出题「数字化转型」= digital transformation

download / upload/ˈdaʊnləʊd / ˈʌpləʊd/v.高频科技下载／上传

搭配download from / to…；upload to a website

辨析down 从服务器到本地 → up 从本地到服务器

出题方向性反义词；写作「上传作品」= upload one's work

gadget/ˈɡædʒɪt/n.次高频科技小装置；小家电

搭配digital / consumer / electronic gadget；household gadget

辨析gadget 小巧装置 → appliance 家电 → machine 机械

出题「智能小家电」= smart gadgets

hardware / software/ˈhɑːdweə(r) / ˈsɒfteə(r)/n.高频科技硬件／软件

搭配hardware-software integration；both are indispensable

辨析两词均不可数

出题写作「软硬结合」= hardware and software integration

innovation/ˌɪnəˈveɪʃn/n.高频写作创新

搭配technological innovation；promote / drive innovation；innovative adj.

辨析innovation 名词（成果/过程） → innovate 动词 → inventive 富创造力的

出题大小作文最常用主题词之一

interface/ˈɪntəfeɪs/n.次高频科技界面；接口

搭配user interface (UI)；graphical interface；at the interface of 在……交界

辨析interface 人机界面 → interaction 交互 → interaction 互动

出题比喻义「学科间交界」= at the interface of two fields

integrate/ˈɪntɪɡreɪt/v.高频写作整合；使结合

搭配integrate A into B；integrate sth. with sth.；integration n.

辨析integrate 融合为一体 → combine 组合 → merge 合并（公司）

出题介词 into/with 高频考点

network/ˈnetwɜːk/n.高频科技网络

搭配social / neural / transportation network；network of sb.

辨析network 网状系统 → system 系统 → web 网

出题「社交网络」= social networks

online/ˌɒnˈlaɪn/adj./adv.高频科技在线的

搭配online shopping / education / payment

辨析online 在线 ↔ offline 线下

出题「线上线下」= online and offline

platform/ˈplætfɔːm/n.高频商业平台

搭配e-commerce / sharing / social platform；on the platform of

辨析platform 平台（虚拟/物理） → base 基地 → stage 舞台

出题「共享平台」= sharing platform

screen/skriːn/n./v.高频科技屏幕；v. 筛选

搭配touch / smart screen；screen out 过滤；screen sb. for sth. 为……筛选

辨析screen 屏幕（名词） ↔ screen 筛选（动词）

出题一词多义是常考点

smart/smɑːt/adj.高频科技智能的

搭配smart phone / city / home / device；be smart about 对……精明

辨析smart 智能（指技术） → intelligent 有智慧的（指人） → clever 聪明

出题一词多义：smart clothes 时髦；smart reply 机智

system/ˈsɪstəm/n.高频科技系统

搭配information / operating / distribution system

辨析system 系统（有组织的） → structure 结构 → method 方法

出题「系统思维」= system thinking

upgrade/ˌʌpˈɡreɪd/v./n.高频商业升级；改进

搭配upgrade software / equipment / product；upgrade service 升级服务

辨析upgrade 品质提升 → update 更新（同步） → improve 改进

出题「产业升级」= industrial upgrading

virtual/ˈvɜːtʃuəl/adj.高频科技虚拟的

搭配virtual reality / classroom / assistant；be virtually certain 几乎肯定

辨析virtual 虚拟的 ↔ real 真实的

出题「虚拟现实」= virtual reality (VR)

wireless/ˈwaɪələs/adj.次高频科技无线的

搭配wireless network / charging / communication

辨析wireless 无线的 ↔ wired 有线

出题「无线充电」= wireless charging

③ 社会民生与心理 · 24 词

accommodate/əˈkɒmədeɪt/v.高频社会容纳；使适应

搭配accommodate 500 people；accommodate to sth. 适应

辨析accommodate 容纳/适应 → host 主办/接待 → adapt 调整

出题翻译「容纳」= accommodate / hold

appeal/əˈpiːl/v./n.高频写作v. 呼吁；吸引；n. 呼吁；吸引力

搭配appeal to sb.（向……呼吁/吸引……）；make an appeal to

辨析appeal 呼吁/吸引 → call 要求 → urge 敦促

出题介词 to 必考；写作「向……呼吁」高频

attach/əˈtætʃ/v.高频介词附；重视

搭配be attached to（依恋/附属）；attach importance to sth.

辨析attach 附加/重视 → attach importance 重视 → attach importance to doing

出题「重视」= attach importance to（介词 + doing）

behave/bɪˈheɪv/v.高频人物行为；表现

搭配behave well / properly；behave oneself；the child behaved badly

辨析behave 行为表现 → act 行动 → perform 演出/表现

出题写作「文明行为」= behave oneself

burden/ˈbɜːdn/n./v.高频写作负担；n. 重担

搭配a heavy burden；be under the burden of；burden sb. with sth.

辨析burden 沉重负担 → load 负载（可减轻） → pressure 压力 → stress 精神压力

出题大作文「减轻负担」= reduce the burden

conflict/ˈkɒnflɪkt/n./v.高频社会冲突；矛盾

搭配in conflict with；a conflict of interest；resolve a conflict

辨析conflict 冲突（对抗） → contradiction 矛盾（逻辑） → dispute 争端

出题「解决冲突」= resolve a conflict

consequence/ˈkɒnsɪkwəns/n.高频写作后果；结果

搭配in consequence（因此）；as a consequence of；serious / far-reaching consequence

辨析consequence 后果（常有因果） → result 结果（中性） → effect 影响

出题「后果」= consequence；「造成」= have serious consequences

custom/ˈkʌstəm/n.高频文化习俗；顾客

搭配traditional customs；customs 海关；customer 顾客（注意拼写）

辨析custom 习俗 → habit 习惯 → usage 用法 → manner 礼节

出题custom vs customer 拼写陷阱

diversity/daɪˈvɜːsəti/n.高频社会多样性

搭配cultural / biological / ethnic diversity；diverse adj. 多样的

辨析diversity 多样性（名词） → diverse 多样的 → variety 品种

出题「文化多样性」= cultural diversity

habit/ˈhæbɪt/n.高频人物习惯

搭配form / get into the habit of doing；good habits

辨析habit 习惯性重复 → custom 习俗 → practice 实践

出题「养成……习惯」= form the habit of doing

impact/ˈɪmpækt/n./v.高频写作影响；冲击

搭配have / exert a (great) impact on；positive / negative impact

辨析impact 强烈影响 → effect 影响（较中性） → influence 长期潜移默化

出题介词 on 必考；写作高分替换

individual/ˌɪndɪˈvɪdʒuəl/n./adj.高频社会n. 个人；adj. 个人的

搭配as an individual；individual differences；individual freedom

辨析individual 个体（强调独特） → person 人 → private 私人

出题「个人与社会」= individual and society

influence/ˈɪnfluəns/n./v.高频写作影响

搭配exert an influence on；have a strong / negative influence on

辨析influence 潜移默化 → affect 直接影响 → impact 冲击

出题写作「产生影响」= exert an influence on

isolate/ˈaɪsəleɪt/v.高频社会隔离；孤立

搭配be isolated from；isolation n. 孤立

辨析isolate 与世隔绝 → separate 分开 → detach 拆开

出题写作「不被孤立」= not be isolated

lack/læk/v./n.高频写作缺乏；缺少

搭配lack sth. / lack of sth.；be in lack of；there is a lack of

辨析lack 缺乏（v.）→ shortage 短缺（n.） → deficiency 不足（技能/营养）

出题「缺乏……」= lack of / for want of

motivate/ˈməʊtɪveɪt/v.高频心理激励；给予动力

搭配be motivated by；motivation n.；a motivated student

辨析motivate 使有动机 → inspire 鼓舞 → encourage 鼓励

出题「有动力做」= be motivated to do

opinion/əˈpɪnjən/n.高频写作观点；意见

搭配hold the opinion that；according to opinion；in my opinion；agree / disagree with

辨析opinion 观点（主观） → view 观点（较正式） → perspective 视角

出题写作开头段必用

pressure/ˈpreʃə(r)/n.高频写作压力；压强

搭配under / under the pressure of；social / academic / work pressure；apply pressure

辨析pressure 压力（可具体量化） → stress 精神压力 → burden 负担

出题「缓解压力」= relieve / reduce pressure

prefer/prɪˈfɜː(r)/v.高频写作更喜欢；宁愿

搭配prefer A to B；prefer to do rather than (do)；would rather do

辨析prefer 主观偏好 → like 喜欢 → like better 更喜欢

出题「比起 A 更喜欢 B」= prefer A to B；to 是介词

quality of life/ˈkwɒləti ɒv laɪf/n.高频社会生活质量

搭配improve / enhance the quality of life；a high / low quality of life

辨析quality of life 生活质量 → living standard 生活水平

出题「提高生活质量」= improve the quality of life

react/rɪˈækt/v.高频人物反应

搭配react to；react positively / negatively

辨析react 反应 → respond 回应 → reply 答复（言语）

出题「对……做出反应」= react to

respect/rɪˈspekt/v./n.高频写作尊重；敬意

搭配in / with respect to（就……而言）；mutual respect；command respect

辨析respect 尊重（人） → regard 看待 → esteem 高度赞赏

出题「在……方面」= with respect to / in terms of

society/səˈsaɪəti/n.高频社会社会

搭配modern society；social / social problems；in society；socialize v.

辨析society 社会 → community 社区 → population 人口
